# Athar — منصة أثر

منصة ويب لتوثيق وعرض مشاريع طلاب جامعة حلوان التكنولوجية.

## المتطلبات
- Node.js إصدار 18 أو أحدث.
- لا توجد مكتبات خارجية مطلوبة؛ الخادم يستخدم مكتبات Node.js المدمجة فقط.

## التشغيل على Windows

1. فك ضغط `athar-platform.zip`.
2. افتح مجلد `athar-platform`.
3. افتح CMD داخل المجلد.
4. نفّذ:

```bat
set ADMIN_KEY=Athar-Admin-Change-This-2026
set BASE_URL=http://localhost:3000
set STORAGE_DIR=./storage
node server.js
```

5. افتح المتصفح على: http://localhost:3000

يمكنك أيضاً تشغيل `node server.js` مباشرة، لكن يجب تغيير مفتاح الإدارة قبل أي استخدام حقيقي.

## التشغيل على macOS / Linux

```bash
ADMIN_KEY='Athar-Admin-Change-This-2026' BASE_URL='http://localhost:3000' STORAGE_DIR='./storage' node server.js
```

## لوحة الإدارة
- افتح زر «الإدارة» في أعلى الصفحة.
- أدخل نفس قيمة `ADMIN_KEY` التي استخدمتها عند تشغيل السيرفر.
- يمكن مراجعة المشاريع، اعتمادها أو رفضها، تمييزها، عرض رسائل الشركات، نتائج الاستبيان، وإضافة مسؤولي الكلية.
- زر CSV يصدر بيانات المشاريع.

## التخزين والنسخ الاحتياطي
- قاعدة البيانات: `storage/data.json`
- الملفات المرفوعة: `storage/uploads/`
- النسخ الاحتياطية اليومية: `storage/backups/` (آخر 20 نسخة).
- لا تحذف مجلد `storage` إذا كنت تريد الاحتفاظ بالبيانات.

## واجهات API الأساسية
- `GET /health`
- `GET /api/projects`
- `POST /api/projects`
- `GET /api/projects/:id`
- `PUT /api/projects/:id` مع ترويسة `X-Edit-Key`
- `DELETE /api/projects/:id` مع ترويسة `X-Edit-Key`
- `POST /api/react`
- `POST /api/inquiries`
- `POST /api/survey`
- `GET /api/staff`
- `/api/admin/*` مع ترويسة `X-Admin-Key`
- `GET /api/admin/export.csv`

## ملاحظات مهمة قبل النشر
1. غيّر `ADMIN_KEY` إلى قيمة طويلة وسرية.
2. استخدم HTTPS وقرص تخزين دائم في الاستضافة.
3. فعّل نسخاً احتياطية خارج الخادم واختبر الاستعادة.
4. أضف مسؤولي الكلية الحقيقيين من لوحة الإدارة.
5. اختبر المشروع مع خمسة مستخدمين على الأقل قبل اعتباره جاهزاً.
6. الأسعار والاستضافة والدومين غير مشمولة في هذا الكود.
7. النسخة الحالية نموذج أولي قابل للتشغيل محلياً وليست مراجعة أمنية أو اعتماداً رسمياً للإنتاج.
